### Aegis false negatives found (honest gaps)

1. **AEGIS-AWS-002 blind spot** — `AppliesTo` covers only `aws_s3_bucket`,
   not the modern `aws_s3_bucket_acl` resource. Trivy's AWS-0092 fired on
   `aws_s3_bucket_acl.assets` (s3.tf:14, `acl = "public-read"`). Mitigated in
   practice: our attack-path rule 104 caught the same exposure. Fix: widen
   002's AppliesTo (source not modified per benchmark constraints).
2. **AEGIS-AWS-204 narrow scope** — covers `aws_instance` but not
   `aws_launch_template`, which also supports `metadata_options.http_tokens`.
   Trivy's AWS-0130 fired on `aws_launch_template.app`/`web`. Fix: widen 204.

### Trivy HIGH/CRITICAL not matched by aegis

| Trivy check | Disposition |
|-------------|-------------|
| AWS-0052/0053/0054 (LB) | covered: 203/201/202 |
| AWS-0080/0177/0180 (RDS) | covered: 007/008/011 |
| AWS-0086/87/91/93 (S3 access block) | covered: 206 (one rule for all four) |
| AWS-0092 (S3 public ACL) | **gap** — see FN #1 above |
| AWS-0104 (open egress) | covered: 005 (severity differs: trivy CRITICAL, ours medium — calibration choice, documented) |
| AWS-0107 (open SSH ingress) | covered: 004 (fires on any open ingress incl. SSH) |
| AWS-0130 (IMDSv2) | **gap** — see FN #2 above |
| AWS-0132 (S3 CMK encryption) | stricter variant of 001 (we flag absent encryption; they require customer-managed keys). Enhancement candidate, not a miss. |
| AWS-0164 (public subnet) | covered: 205 |

**Net: of 19 unique trivy HIGH/CRITICAL items, 16 are covered by aegis rules,
2 are genuine aegis gaps (002 scope, 204 scope), 1 is a stricter variant.**

## 8. Limitations

- Box under memory pressure (~330 MiB free) inflated variance, especially
  trivy's (stdev 902ms). Re-run on an idle machine for tighter CIs.
- `/usr/bin/time` absent; peak RSS via Python `resource` module (fresh
  interpreter per measurement — no accumulation).
- Trivy peak RSS on the large corpus not measured.
- Finding-count parity is scope-dependent: trivy's bundle is broader (incl.
  8 LOWs); aegis adds path correlation + fix + API that trivy config doesn't bundle.
- Cold-cache: only run 1 measured cold; a proper cold-cache study would drop
  page cache between runs (needs root).
